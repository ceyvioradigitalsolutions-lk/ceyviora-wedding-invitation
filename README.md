## How to run
1. Extract the complete ZIP.
2. Open `index.html` in Chrome or Edge.
3. Click **OPEN THE INVITATION**.
4. Scroll to view the animated couple, Wedding Details, and Closing sections.

## Optional real couple photo
Place your portrait as `assets/photos/couple-hero.jpg` (recommended 1600 × 2000 px, vertical 4:5). If not present, the included demo portrait is displayed. This demo portrait is illustrative, not the real couple.
